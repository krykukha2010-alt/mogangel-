# Листок — игровой дневник питания и мыслей

Готовый статический веб-прототип. Не требует Node.js, сборки или внешних библиотек.

## Что работает
- Дневник питания: добавление, редактирование, удаление записей.
- Подсчёт калорий, белков, жиров и углеводов на основе введённых значений на 100 г.
- Настраиваемые дневные цели КБЖУ.
- Игровые баллы: +5 за каждую из первых двух новых записей о питании в календарный день.
- Магазин наград, инвентарь и история операций.
- Серия огоньков за дни с записями о питании.
- Дневник мыслей: создание, поиск, редактирование и удаление заметок.
- Светлая/тёмная/системная тема, восемь палитр, ручные цвета и пять стилей.
- Экспорт данных в JSON.
- Локальное сохранение в браузере.

## Важно
Это стартовый прототип, не готовое приложение с аккаунтами или облачной синхронизацией. Данные хранятся локально в браузере на том устройстве, где вы открываете сайт. Очистка данных браузера может удалить их — используйте экспорт резервной копии.

Игровые баллы в этой версии начисляются за первые две новые записи о питании за календарный день. Приложение не ограничивает количество записей и не требует соблюдать интервалы между приёмами пищи. Это сделано, чтобы игровая механика не поощряла пропуск еды.

## Как опубликовать через GitHub Pages
1. Создайте новый репозиторий на https://github.com/ и назовите, например, `listok-app`.
2. Распакуйте архив и загрузите `index.html` и `README.md` в корень репозитория. Можно нажать **Add file → Upload files**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Подождите завершения публикации. Адрес сайта появится в разделе Pages и будет иметь вид `https://ВАШ-ЛОГИН.github.io/listok-app/`.

## Как проверить без публикации
Просто откройте `index.html` в современном браузере. Для полноценного тестирования лучше запустить локальный статический сервер, но для большинства функций достаточно открыть файл напрямую.

## Следующие шаги для настоящего продукта
