# Mogangel — дневник привычек

Мобильное веб-приложение с дневником питания, заметками, игровыми баллами, наградами и настройками оформления.

## Публикация на GitHub Pages

1. Загрузите в корень репозитория все файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `README.md`.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Дождитесь публикации сайта.

## Установка на Android как приложения

1. Откройте опубликованный GitHub Pages URL в Chrome на Android.
2. Нажмите меню Chrome `⋮`.
3. Выберите **Установить приложение** или **Добавить на главный экран** (название зависит от версии Chrome).
4. Подтвердите добавление. На главном экране появится значок «Mogangel».

Для установки PWA нужен HTTPS; GitHub Pages его предоставляет. Данные дневника сохраняются локально в браузере на устройстве. Очистка данных браузера может удалить записи, поэтому периодически используйте экспорт JSON в настройках приложения.


Название приложения: Mogangel. Иконка взята из изображения, выбранного пользователем.
